# Markdown 公式阅读器

一个可直接在浏览器中打开的单文件 HTML 工具，用于阅读、编辑和预览包含 LaTeX 数学公式的 Markdown 文档。

## 使用方式

1. 下载本仓库，双击 `index.html`，使用 Edge、Chrome 等现代浏览器打开。
2. 点击「打开 Markdown」选择 `.md`、`.markdown` 或 `.txt` 文件，也可以将文件拖入页面。
3. 在左侧编辑内容，右侧会实时更新预览。
4. 点击「保存 Markdown」下载编辑后的文件；点击「打印 / 保存 PDF」调用浏览器的打印功能。

页面内置了示例，打开后即可查看公式的效果。

## 功能

- 支持 Markdown 标题、列表、引用、表格、链接和代码块。
- 使用 KaTeX 渲染行内公式和独立公式。
- 单击预览中的公式，复制其原始 LaTeX 代码；也可以用 Tab 聚焦公式，再按 Enter 或空格复制。
- 复制内容不含两侧分隔符，保留原始反斜杠、空格和换行。
- 复制成功或失败时显示提示；提供剪贴板 API 不可用时的兼容处理。
- 支持拖入文件、保存 Markdown 和打印 / 保存 PDF。
- 支持窄屏布局。

## 公式语法

| 类型 | 写法 |
| --- | --- |
| 行内公式 | `$x^2 + y^2 = z^2$` |
| 行内公式 | `\(e^{i\pi} + 1 = 0\)` |
| 独立公式 | `$$\frac{a}{b}$$` |
| 独立公式 | `\[\int_0^1 x^2\,dx = \frac{1}{3}\]` |

独立公式也可以跨行书写：

```markdown
$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$
```

代码块和行内代码中的公式标记保持为代码。

## 运行说明

无需安装软件或启动服务。Markdown 解析和公式渲染在浏览器本地完成；打开的 Markdown 文件不会由该工具上传到服务器。

当前版本通过 jsDelivr CDN 加载以下组件，打开时需要能够访问这些资源：

- [Marked](https://github.com/markedjs/marked)：Markdown 解析。
- [KaTeX](https://katex.org/)：数学公式排版与字体。
- [DOMPurify](https://github.com/cure53/DOMPurify)：清理生成的 HTML。

Markdown 中引用的远程图片等资源仍会按对应地址加载。相对图片路径以阅读器所在目录为基准。

编辑内容不会自动保存，关闭页面前请使用「保存 Markdown」。剪贴板权限受浏览器设置影响，无法自动复制时页面会提示手动复制。
